    SO FUNKTIONIERT ES

    Einmal einrichten.
    Jeden Monat nutzen.

    1. Deinen Namen und die Mannschaft eintragen.
    2. Wochentage und Trainingszeiten hinterlegen.
    3. Eine eigene vierstellige PIN wählen und speichern.
    4. Später deinen Namen auswählen und die PIN eingeben.
    5. Monat oder Jahr wählen und PDFs erstellen.

    Deine Daten bleiben zunächst in diesem Browser. Mit dem verschlüsselten Backup in deinem persönlichen Bereich kannst du sie auf ein anderes Gerät übertragen. Löschen der Browserdaten entfernt auch deine lokalen Trainerdateien.

    Was ist sichtbar?

    Die Namen in der Auswahl sind sichtbar. Wochenplan, Mannschaft und Unterschrift sind je Trainer verschlüsselt. PDFs und PINs werden nicht an einen Server gesendet.

    Änderungen an vorhandenen Trainern: PIN eingeben und „Meinen Plan bearbeiten“ wählen. Die neue Trainerdatei ersetzt die bisherige.

    Verwaltung

    Deine Daten, deine PIN.

    Das Portal wird über GitHub Pages ausgeliefert. Name und PIN werden zur Anmeldung nicht an einen Server gesendet. Die lokale Speicherung erfolgt in der Browser-Datenbank dieses Geräts. Es gibt keine zentrale Anmeldung, keine Identitätsprüfung und keine Synchronisierung.

    Wochenplan und Unterschrift werden mit AES-256-GCM verschlüsselt. Der Schlüssel wird mit PBKDF2-SHA-256 (600.000 Durchläufe) aus deiner vierstelligen PIN abgeleitet. Eine vierstellige PIN hat nur 10.000 mögliche Werte: Wer die verschlüsselte Datei besitzt, kann sie offline ausprobieren. Das Verfahren ist deshalb kein belastbarer Schutz für sensible Unterschriften.

    Die Namen in der Auswahl bleiben sichtbar. Optional kann die Vereinsverwaltung verschlüsselte Trainerpakete im Repository hinterlegen. Diese Dateien können heruntergeladen werden; ihr Schutz ist ebenfalls auf die kurze PIN begrenzt.

    Es gibt keine Wiederherstellung ohne PIN. Sichere deine Trainerdatei mit „Verschlüsseltes Backup“. Das Löschen von Browserdaten entfernt die lokale Kopie. Nach dem Entsperren bleiben Daten im Arbeitsspeicher dieses Tabs. „Bereich sperren“ oder Schließen entfernt den Zugriff im Portal. Heruntergeladene PDFs sind unverschlüsselt.
